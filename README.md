# PopVault

Landing page for **PopVault** — authenticated luxury watch resale.
First drop: **Audemars Piguet × Swatch Royal Pop** (16 May 2026).

## Files
- `index.html` — full single-file landing page
- `vercel.json` — Vercel deploy config
- `setup-google-sheets-waitlist.md` — 5-min guide to wire the waitlist form to a Google Sheet you own (no backend needed)
- `PopVault-Launch-Checklist.md` — Shopify go-live checklist

## Local preview
Open `index.html` in any browser.

## Deploy
- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` → `/ (root)`
- **Vercel:** `vercel deploy --prod`
- **Netlify:** drag the folder onto app.netlify.com/drop

## Waitlist
Submissions land in a Google Sheet you control. Follow `setup-google-sheets-waitlist.md`.
